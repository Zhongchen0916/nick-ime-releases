# Nick 输入法 · 安装包

这里只放 Windows 安装包和自动更新清单，源码在私有仓库里。

## 安装
1. 到 [Releases](https://github.com/Zhongchen0916/nick-ime-releases/releases/latest) 下载最新的 `NickIME-Setup-x.y.z.exe`
2. 双击安装（不需要管理员；没装小狼毫拼音的话会顺带装，那一步要点一次「允许」）
3. 装完按托盘图标 → 设置 → 翻译 填自己的 Claude API Key（或改用国内模型 / 机器翻译）

## 更新
程序每天会自己检查 `latest.json`，有新版会弹窗提示，点「下载并安装」即可；也可以在 设置 → 常规 里手动点「检查更新」。
